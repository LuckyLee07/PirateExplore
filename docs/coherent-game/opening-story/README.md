## Art provenance

All nine source images were generated through the built-in `image_gen` tool, using the inspected approved `Images/UI/CleanVoyage/harbor-clean-ne.png` as the style reference and corresponding original plot images as composition/beat references. The desired shared material language is sunny clean low-poly 2.5D, turquoise sea, cream stone, blue roofs, lime palms and naturally scaled people. Raids and eruption keep their appropriate dramatic subjects.

`generated-manifest.json` contains exact prompts, original generation paths, packaged outputs, dimensions, transparency, hashes, reference hash and the unchanged narrative/source hashes. `scene3-refinement.json` records the targeted imagegen edit after manual review found seventeen stones in the first result. Removing the foreground-left wave stone gives the exact sixteen-rune count. Original generator outputs and all original game art are preserved.

Packaged PNGs are the generated bytes, without recoloring, hand-painted replacements, baked captions or upscaling. Native source rectangles remove transparent padding from the three animated sprites at presentation time; the PNG alpha is unchanged.
