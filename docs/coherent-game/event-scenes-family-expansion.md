# Event entry-scene family expansion

The approved first visual gate remains frozen at `3f588c7821cfeb24d1beece3f49055e22a7f6a65`. This separate expansion branch continues only EventLayer presentation and its helper/assets/tests. It does not change original event dispatch, controller, map, economy, save or transaction methods. EventBaseView and shared SDButton are unchanged.

## Exact coverage, not full-surface acceptance

The machine-checked ledger is `event-scene-coverage-v2.json`, generated by `tools/tests/event_scene_identity_coverage.py` against the immutable decoded packaged CSV and the actual Lua resolver.

Clean entry scenes cover 57 of 344 event records, representing all ten dispatch families:

- Battle: 3108 only (1/282), exact skeleton10001 on the boarded deck; no actor remains when occupied.
- Resource: 3067,3068,3070 (3/9), approved quarry/iron/timber rafts.
- Supply: 3053 (1/1), current original breads data, with status 发现补给.
- Tavern: 3004–3019 (16/16), explicitly enumerated IDs. Each summary reads its actual Carryitems identity, currency and price.
- Black market: 3020–3035 (16/16), explicitly enumerated IDs, trading stall with closed cargo and scale; no invented live stock or price.
- Resurrection: 3003 (1/1), memorial markers.
- Next-map gate: 3052 (1/1), gateway with state-specific original unlock context.
- World-chart/teleport entry: 3002 (1/1), nongeographic navigation table.
- Arena: 3036–3051 (16/16), explicitly enumerated IDs, empty challenge ring.
- Eternal arena: 3074 (1/1), distinct endless-challenge ring, original checkpoint records/levels/costs.

All 281 other battle identities and six distinct resources (3069,3071,3072,3073,3075,3076) remain explicitly unreviewed fallback art. The ledger lists every ID and name. Old GID art in these fallbacks is **not finished clean art**. Enemy GIDs are reused for unrelated meanings across regions, so neither the new resolver nor the coverage claim equates GID with geography.

**WorldMapLayer.lua's reachable chapter selector remains legacy and is not accepted by the new world-chart entry prop.** Existing EventDetailsLayer recruitment/revival/market/cargo pages retain their prior coherent implementation; this change does not constitute new visual acceptance of those downstream surfaces.

## Behavior and composition

- Family-specific site context replaces the generic arrival wording for reviewed scenes. Occupied combat/resources remain explicitly occupied. Next-map occupied state describes the opened next sea.
- The actual current event cost appears before long narrative. Selecting an eternal-arena checkpoint displays that selected original record's cost before the narrative instead of leaving the base-entry tool cost in the main summary. The existing `checkJumpToEternalArena(record.costs,record.level)` callback is unchanged.
- Dense checkpoint pages reserve native table and prose viewports while retaining their semantic scene and the fixed primary/Leave dock. At 360×640, prose and checkpoint rows scroll; neither can displace the actions.
- The generic original SDButton has no cancelled-touch handler. EventLayer's two local controls now release their painted and long-press state on native cancellation without invoking a callback. No shared button helper or class changed.
- All full background planes retain explicit negative z depths; text and live controls survive visit-induced equal-z reordering.
- Six new bitmap props were generated through built-in imagegen, visually inspected and copied byte-for-byte. Transparent RGBA masters are preserved without raster processing, resizing, retouching or overwriting original assets. `provenance-v2.json` records original source filenames, prompt keys, dimensions, alpha extrema, opaque bounds and SHA-256. Arena/memorial alpha maxima are 254 in the original outputs and are deliberately preserved.
- Neutral pale teal fields behind chart, memorial and arena models intentionally assert no new island or map geography. Floating tavern, supply, black-market and gate props use the approved harbor water texture.
- No added visible glyph is missing from the unchanged CleanVoyageSans subset.

## Proposed separate world-chart selector pass

Keep this expansion frozen before touching WorldMapLayer. A narrow next pass can replace only selector composition/paint with a native, scrollable 16-chapter route list and an actual selected chapter summary, keeping original chapter IDs/names and current/unlocked/locked states. Avoid a newly drawn fantasy map: a chapter list can be faithful without inventing geographic relationships.

Retain `moveToMapByIndex` as the routing and entitlement gate: its `mapMaxIndex` and ready-state checks, `owner:enterNextMapEnter(false,index,true)` check-only call, expansion purchase path, and eventual original `enterMapByIndex` dispatch must remain authoritative. Retain `getMapShopInfoByMapIndex`, original diamond price, `showBuyView` consequential closure, `unlockMapDatas` save/economy semantics, and `backToCurMap` ownership completion. New presentation must not grant an unlock, spend currency in a read-only preview, infer payment availability, or alter the order/identity of chapters.

Before acceptance, run actual native pixels at compact/base/large sizes plus controlled locked/unlocked/current/newly-unlocked chapter fixtures, current return, selection/confirmation cancel, exact in-memory original cost deltas only, repeated/dragged/stale input, dynamic children, modal owner cleanup and departure while an animation/confirmation is open. Keep unavailable online/purchase support explicit. That is a proposed follow-on scope, not part of this commit.
