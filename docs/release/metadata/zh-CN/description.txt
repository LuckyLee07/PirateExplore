一只封印着海盗王与掠夺者号的水晶瓶，把你卷入了未知海域。

在《海上探险家》中，你将整备船只与补给，沿羊皮纸海图探索迷雾，面对会改变航程结果的事件与选择。炮火不会结束战斗：击破敌船甲板后，你还要带领船员登船接舷，把舰炮阶段创造的优势带入近身交锋。

第一章体验包括：

• 在安全与风险航线之间作出选择；
• 探索迷雾、处理海上事件并管理有限补给；
• 经历舰炮战与接舷战相连的双阶段战斗；
• 寻找散落的封印符文，揭开海盗王诅咒；
• 返港修复和升级船只，为下一次远航做准备。

当前版本聚焦完整的第一章冒险，不包含广告、抽卡、钻石商城或付费复活。你的航线选择、战斗结果和升级决定共同塑造这次远航。
