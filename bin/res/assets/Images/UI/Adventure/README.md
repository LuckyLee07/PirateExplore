# Adventure B presentation assets

Generated specifically for this UI refresh from the selected light-cartoon-adventure art direction. These are reusable decoration/sprite assets, not screenshots or screen-sized interface replacements.

- `harbor.png`: 1280×640 RGB harbor illustration, displayed within native layouts.
- `ship.png`: 256×256 RGBA transparent overhead ship, uniformly fitted inside the original 64-unit logical tile node.

Original generation masters and exploratory variants are excluded. All labels, controls, inventory data, fog, terrain and events remain native game content.
