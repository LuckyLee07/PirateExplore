# Home-only B illustrated assets

These five images are original generated production assets for the harbor refinement. They share broad painted shapes, a restrained sea/ink/sand/coral palette and adult proportions. Full generated masters remain outside the repository.

- `harbor-b.png`: primary harbor illustration; cover-fit with one uniform scale, never stretched independently.
- `growth-b.png`, `build-b.png`: real talent and construction navigation illustrations, with runtime labels and clickable controls.
- `crew-107.png`: wood-shield helmsman (木盾舵手), only for original soldier ID 107.
- `crew-124.png`: ship doctor (船医), only for original soldier ID 124.

Portraits are rendered only when their actual type appears in the saved selected formation. Multiple members of one type use one portrait plus the true count. Unselected reserve units are not pictured as active crew. Other types receive a neutral silhouette and their actual CSV name. No named character identity is invented.

The original first-batch harbor and ship assets remain in the parent directory because expedition and chart presentation are outside this refinement's scope.
